# キリリンSHOP 管理アプリ

中古アパレルせどり（メルカリ転売）向けの在庫・利益管理PWAアプリです。

---

## 使い方

### iPhoneでホーム画面に追加する方法（PWA）

1. iPhoneのSafariで `index.html` を開く
2. 画面下の「共有」ボタン（□↑）をタップ
3. 「ホーム画面に追加」を選択
4. 「追加」をタップ

→ アプリアイコンからいつでも起動できます（オフラインでも動作）

### PCで使う場合

`index.html` をブラウザで直接開くだけでOKです。

## 機能一覧

### ダッシュボード
- 月利（月ごとに切り替え可能）
- 月のメルカリ残高入金額
- 仕入れ総額（在庫中の商品）
- 年間総利益
- 利益率・回転率
- 在庫数内訳（未出品 / 出品済み / 販売済み）

### 商品登録
右下の「＋」ボタンから登録します。

| 項目 | 説明 |
|------|------|
| 商品写真 | 複数枚登録可能 |
| ステータス | 未出品 / 出品済み / 販売済み |
| 商品名 / メモ | 自由記述 |
| 仕入れ店舗 | 店舗名 |
| 仕入額 | 円単位で入力 |
| 販売額 | 販売済み時に入力 |
| 手数料 | メルカリ手数料（通常10%） |
| 送料 | 実費を入力 |
| 販売日 | 販売済み時に入力 |

### 利益計算

```
利益 = 販売額 - 仕入額 - 手数料 - 送料
利益率 = 利益 ÷ 販売額 × 100
回転率 = 販売済み数 ÷ 登録総数 × 100
```

### 在庫管理
- 未出品・出品済みの商品を一覧表示
- フィルタータブで絞り込み可能
- カードをタップで詳細表示・編集

### データ管理（設定画面から）
- **JSONエクスポート**：全データをバックアップ
- **JSONインポート**：バックアップから復元（既存データに追加）
- **CSVエクスポート**：帳簿・マネーフォワード用

---

## データ保存について

現在は **ブラウザのlocalStorage** に保存しています。

- 同じブラウザ・同じ端末からのみアクセス可能
- ブラウザのデータを削除すると消えます
- 定期的に「JSONエクスポート」でバックアップを取ることを推奨します
